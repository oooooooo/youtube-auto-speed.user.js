# AGENTS

## Versioning

- Bump `@version` in the header of `youtube-auto-speed.user.js` in the same
  commit as every change that users get.
  Userscript managers only update installed copies when `@version` changes.
  - `feat`: add 0.1.0 and reset the patch to 0 (`1.5.2` → `1.6.0`)
  - `fix`: add 0.0.1 (`1.5.2` → `1.5.3`)
